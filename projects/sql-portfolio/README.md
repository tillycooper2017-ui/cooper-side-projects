question against a sample dataset. You do not need to read SQL to follow along:
every query has a plain-English explanation of the question, what it does, and
what the answer means.

## How to read each query
Every `.sql` file starts with a comment block in this format:

```sql
-- QUESTION:   The business question, in plain English.
-- WHY IT MATTERS: Who would ask this and what decision it informs.
-- HOW IT WORKS:   Step by step, no jargon.
-- ANSWER:     The result, in one or two sentences.
```
